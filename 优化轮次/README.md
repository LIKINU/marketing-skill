## 为什么保留

这些文件的价值**不是「记录我们干了什么」**，而是三条：

1. **每条问题都带证据**（文件 + 行号 + 原文片段）—— 后来人能复核，不会「听说改过」。
2. **未做项写在明处并附理由**（如「批量改写会让教材失真，所以只标注」）——
   防止下一轮又把同一件事重做一遍。
3. **收敛曲线留在纸面上**：R1 报 19 条 → R2 报 8 条 → R3 报 3 条 → R4 报 0 条（机械扫描），
   这是「该停在哪一轮」的客观依据，而不是凭感觉决定还要不要跑。

## 五轮累积的一条通式

**教材教对 → 骨架给位 → 脚本检查 → 文档承诺** —— 四环缺一，交付质量都随机。

- R1 修的是「文档写了、**脚本没查**」
- R3 修的是「脚本查了、**骨架没给位**」
- R4 修的是「骨架给了位、**教材把内容喂错了**」
- R5 修的是「都对得上、但**没人问『投资人会不会信』**」
